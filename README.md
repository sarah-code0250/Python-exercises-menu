# Python-exercises-menu
Excercises menu: parking lot, discount and pet sales

## Parking lot, discount and pet sales
A collection of three exercises developed on Programiz using the Python programming language, designed to calculate a product discount, parking costs, and the cost associated with a pet.

## Technologies
- Python developed on Programiz

## Purpose 
A project for programming beginners, designed to practice using variables, arithmetic operators, and conditionals, as well as the repetitive algorithmic structure "while."
